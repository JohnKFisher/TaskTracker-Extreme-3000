# Working Changelog

Internal source material for public release notes; keep entries understandable to non-technical users.

## Unreleased

### Added
- Tickets tab now has a small Newest / A–Z toggle beside the ticket count, for switching between newest-first and subject-alphabetical order. The choice is remembered per machine.
- Notes tab has a new Short-Term section. The three sections are stacked For next meeting, Short-Term, Long-Term.

### Changed
- The Notes tab's "General" section is now called "Long-Term". The text already in it is untouched — only the heading changed.

### Fixed
- The Light/Dark/Auto theme choice now actually sticks between launches. It was being silently discarded on save, so the app fell back to Auto every restart no matter what you picked.
- A brand-new install now starts with the Standing column visible, as intended. Setting up the app on a fresh machine used to hide it until you went and turned it back on.
